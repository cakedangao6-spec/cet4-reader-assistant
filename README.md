# CET-4 Reader Assistant

English | [简体中文](./cet4-reader-assistant/README.zh-CN.md)

This repository is prepared for the public showcase of **CET-4 Reader Assistant**, a local-first Windows desktop app for CET-4 reading and listening practice.

The active project is:

- [cet4-reader-assistant](./cet4-reader-assistant)

It provides reading passage cleanup, word lookup, vocabulary export, OCR-assisted material processing, local audio playback, faster-whisper listening transcription, article navigation, and optional GPU acceleration with CPU fallback.
