# CET-4 阅读助手

这是一个面向英语四级阅读训练的桌面辅助工具。你可以直接把英文文章粘贴进去，点击单词查看释义，双击加入生词，并把当天的词表固定导出，方便后续复习。

## 主要功能

- 直接粘贴英文文章后开始阅读，并自动尝试拆分文章区/题目区
- 启动时自动恢复上次文章、题目、答案、生词和高亮
- 点击文章中的单词即可查词
- 离线优先查询本地英汉词典
- 自动处理常见词形变化，例如 `studies -> study`
- 双击单词加入生词，自动去重和排序
- 支持右侧手动输入单词加入生词
- 支持 `Ctrl+F` 搜索文章并高亮结果
- 选中文本后右键即可高亮 / 取消高亮
- 固定导出生词到 `vocab/vocab.txt`
- 导出时自动保存历史到 `vocab/history/YYYY-MM-DD_HH-MM-SS_vocab.txt`

## 查词顺序

1. 本地离线词典
2. 中国网络环境通常可访问的在线词典
3. 其他在线翻译接口
4. 都失败时显示“暂无释义”

## 离线词典

项目默认支持放在 `data/dictionaries/` 下的 CSV 词典文件。

- `cet_common.csv`：随项目保留的常用词离线词表，覆盖高中、四级、六级常见词
- `ecdict.sqlite3`：安装时可自动生成的完整离线索引库
- `ecdict.csv`：安装时下载的 ECDICT 源数据
- `lemma.en.txt`：可选下载的词形还原数据

安装流程会尝试自动下载 ECDICT 数据。即使下载失败，程序仍可使用已经存在的本地词典继续运行。

## 目录约定

- 主程序：`cet4_reader/`
- 离线词典：`data/dictionaries/`
- 当前导出生词：`vocab/vocab.txt`
- 历史词表：`vocab/history/`

## 直接粘贴文本

左侧上方是文章区，下方是题目区，中间分割线可以拖动。复制英文文章后，直接按 `Ctrl+V` 粘贴到文章区；如果识别到 `36.`、`46.`、`Questions 36-40` 或 `Question 1` 等题目标志，程序会自动把题目放到下方题目区。

## 会话

- 上次文章、题目、答案、生词和高亮会自动保存到 `runtime/session.json`
- 点击“一键清空 / 重新开始”会清空当前会话，但不会删除 `vocab.txt`、历史记录或离线词典
- 点击“打开生词本目录”会直接打开 `vocab.txt` 所在文件夹
