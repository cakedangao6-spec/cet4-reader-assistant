# QUICK START

## 启动方式

1. 双击 `run.bat`
2. 第一次运行时，程序会自动安装依赖并准备词典
3. 安装完成后会自动打开主界面

## 如何粘贴文章

1. 复制英文文章
2. 点击左侧“粘贴文章”文本框
3. 按 `Ctrl + V`
4. 程序会尝试自动把题目拆到下方题目区
5. 文章出现后即可直接查词、加词和导出

## 怎么加入生词

- 在文章区双击单词
- 或在右侧输入框手动输入单词后点击“添加”

## 怎么调整文章和题目

- 左侧上方是文章区，下方是题目区
- 中间分割线可以拖动
- 题目区可直接编辑答案，例如 `A 46.`

## 怎么高亮

- 选中一个单词或一段文本后点击鼠标右键
- 未高亮时会添加高亮
- 已高亮时会取消高亮

## 怎么搜索

- 点击顶部搜索框，或按 `Ctrl + F` 聚焦搜索框
- 输入单词或短语
- 按回车跳到下一个结果

## 怎么重新开始

点击“一键清空 / 重新开始”，会清空当前文章、题目、答案、生词、搜索和查词区，但不会删除已经导出的词表。

## 怎么导出

1. 点击工具栏“导出 vocab.txt”
2. 当前词表固定写入：
   `vocab\vocab.txt`
3. 每天的历史快照固定写入：
   `vocab\history\`

例如：

- `vocab\vocab.txt`
- `vocab\history\2026-05-17_20-11-35_vocab.txt`

## 怎么打开生词目录

点击顶部“打开生词本目录”，会直接打开 `vocab.txt` 所在文件夹。
